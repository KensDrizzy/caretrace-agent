一、核心发现

🎯 专门"校园心理"数据集极少

以"校园心理/学生心理健康"命名的独立开源数据集极为稀少。目前唯一明确面向大学校园场景的大规模对话数据集是 CPCD (Psy-Chronicle)（9万对话/1145万字）。主流数据集多为通用中文心理咨询语料，但大量样本天然覆盖考试、科研、宿舍、失恋、就业等学生高频场景，可按关键词筛选子集。

📈 可直接免费下载的中文对话数据充足

至少 12 个中文心理咨询对话/问答数据集可在 GitHub 或 ModelScope 直接免费下载，总规模超过 300 万条对话/问答。其中 EmoLLM 数据集集合采用 MIT 许可可商用，SoulChatCorpus 规模最大（151万轮），CPCD 校园相关性最高。

⚠️ 多数多轮对话由 LLM 合成

中文心理对话数据集中，多轮部分大多由 GPT-4/ChatGPT 合成生成（SoulChat、SMILECHAT、CPCD、PsyDTCorpus 等），真实咨询记录极少。相对真实的包括：CPsyCounD（基于真实咨询报告重构）、MDD-5k（基于真实病历合成）、efaqa-corpus-raw（网络爬取真实用户倾诉）。

🔒 许可与获取方式差异大

仅 EmoLLM 数据集集合明确采用 MIT 许可可商用。多数数据集未声明许可或仅限研究用途。EFAQA 系列需购买证书，PsyQA/STAMPsy/D4 需签署协议申请，AuraDial 需非商业协议。商用前务必逐一核实许可条款。

四、第一梯队：可直接免费下载的中文对话数据

以下数据集可在 GitHub / ModelScope / HuggingFace 直接免费获取，已具备或可轻松转换为微调格式，是最优先考虑的候选。

1. EmoLLM 数据集集合 — MIT许可，唯一可商用
中文 免费 已查证
来源：GitHub
规模：16个子集，总计>170万条
许可：MIT（可商用）
格式：QA / 多轮对话 / CoT推理
整合了 SMILE、CPsyCounD、SoulChat 等多个知名数据集，含 R1 蒸馏推理数据（psychology-10k-Deepseek-R1-zh）。配套 xtuner/LLaMA-Factory 微调配置。部分子数据集为角色扮演数据（如"舔狗""老母亲"），专业性参差不齐，需自行筛选高质量部分。在所有调研数据集中许可最宽松，是商用场景的首选。
2. SoulChatCorpus — 规模最大的中文共情对话语料
中文 免费 已查证
来源：GitHub / ModelScope
规模：258,354对话 / 1,517,344轮
许可：代码Apache 2.0；数据集随项目分发
格式：已统一为"用户：xxx\n心理咨询师：xxx"指令格式
单轮数据>15万条（回答>50万条），多轮数据约100万轮，混合后>120万样本（过滤约9万条风险数据）。覆盖期末考试、科研压力、宿舍关系、失恋等学生高频场景。多轮数据由 GPT-4 合成，存在模式单一风险。EMNLP 论文验证质量。模型权重基于 ChatGLM-6B 仅限非商业研究。
3. CPCD (Psy-Chronicle) — 唯一面向大学校园的长程咨询数据集 ⭐
中文 免费 已查证
来源：GitHub / arXiv
规模：100学生档案 / 90,000对话 / 约1,145万中文字符
许可：论文标注"open-source"
格式：学期级长程多轮对话，含学生档案+校园压力事件+跨会话记忆更新
本调研中唯一明确面向大学校园场景的大规模对话数据集。建模学期级长程咨询过程，含学生背景信息和事件触发机制，非常适合校园心理大模型微调。另含 CPCD-Bench 评估基准。数据为合成生成（基于结构化 pipeline），非真实咨询记录；长程对话对模型上下文窗口要求较高；2026年新发布，社区验证尚少。
4. SMILECHAT (MeChat)
中文 免费 已查证
来源：GitHub / EMNLP 2024 Findings
规模：55,165条多轮对话；转换后310,087训练样本
许可：未明确声明（GitHub公开）
格式：已提供 instruction 格式转换脚本，含完整 system prompt
将 PsyQA 单轮数据通过 ChatGPT 扩展为多轮对话（99% GPT-3.5, 1% GPT-4），解决了 PsyQA 缺乏多轮结构的问题。基于真实心理互助 QA 扩展，话题覆盖高考焦虑、睡眠、情感等学生场景。平均对话长度约11.4轮，回复偏长（平均85.8字）。含真实测试集 PsyTest。专家评估质量优于基线。
5. cPsychQASet (PsyChatbot)
中文 免费 已查证
来源：GitHub / ACM TALLIP
规模：约89,000条心理咨询问答三元组
许可：论文称数据已发布（GitHub公开）
格式：问题-答案-类别 三元组，基于认知行为疗法(CBT)
数据来自三个专业心理咨询论坛（xinli001等），为真实用户提问和回复。基于 CBT 理论框架，面向抑郁人群，适合 CBT 取向的心理问答微调。规模较大（89K）。问答三元组格式简单，缺乏多轮上下文，适合作为单轮 QA 训练数据或与多轮数据集混合使用。
6. CPsyCounD — 基于真实咨询报告重构，质量最高
中文 免费 已查证
来源：GitHub / ACL Findings 2024
规模：3,134份真实报告 → 3,134条对话 + 500条评估
许可：未明确声明（GitHub公开）
格式：多轮对话 + 5种咨询意图 + 9种情绪标签
中科院深圳先进院 XinHai 团队出品。基于3,134份真实心理咨询报告（来自壹点灵等平台）通过 Memo2Demo 方法重构为对话，质量高于纯 LLM 生成数据。含评估基准 CPsyCounE（500条）。规模较小（3.1K），通常作为高质量种子数据或评估集使用。对话由 LLM 从报告重构，非原始咨询录音转写。
7. PsyDial — 首个完全开源的中文长程心理咨询对话
中文 免费 已查证
来源：GitHub / ACL 2025 Main
规模：平均每个对话37.8轮（远超同类）；分D0-D4多分割+D101测试集
许可：未明确声明（HuggingFace公开）
格式：长程多轮对话，D101为专业书籍人工对话测试集
对话轮次长（平均37.8轮），更接近真实长程咨询。采用 RMRR（检索-掩码-重构-精炼）方法专门做了隐私保护重构，是伦理上最稳妥的选择。D101 测试集为101个专业咨询书籍人工收集对话，质量高。半真实数据（LLM重构），非原始真实咨询。HuggingFace 多分割免费下载。
8. PsyDTCorpus (SoulChat2.0)
中文 免费 已查证
来源：GitHub / ACL 2025 Main
规模：5,000对话 / 90,365轮（平均18轮/对话）
许可：未单独声明（模型需遵循基座协议）
格式：OpenAI messages格式，含system prompt指定咨询师流派（如REBT）
心理咨询师数字孪生对话数据集，含特定咨询师语言风格与疗法技术。可直接用 LLaMA-Factory 微调。人工评估在谈话技术、关系建立、疗法技术等维度优于 SoulChat/SMILE/CPsyCoun。数据由 GPT-4 基于12个真实案例合成。规模相对较小（5K对话），模型仅用于科研。
9. SoulChat-R1 (CATCH) — 唯一含显式思维链的中文心理咨询数据
中文 免费 已查证
来源：GitHub / EMNLP 2025 Findings
规模：未在README中给出具体对话数
许可：Apache 2.0
格式：结构化对话（SST三阶段标注）+ 显式MDP CoT（<think>标签）
当前少有的含显式思维链的中文心理咨询数据集，CoT 包含记忆增强→全局规划→策略推理三步，适合训练 R1 类推理模型。严格遵循单次单元咨询疗法（SST）流程，治疗保真度高。数据为多智能体合成。具体规模未公开，SST 疗法覆盖范围有限（单次咨询）。
10. Psy-Insight
中英双语 免费 已查证
来源：GitHub / arXiv 2025
规模：中文431会话/5,776轮；英文520主题/6,208轮
许可：未明确声明（GitHub公开）
格式：多轮对话 + 逐步推理标注 + 多任务标签（情绪/策略）
少有的中英双语心理咨询数据集。含逐步推理（step-by-step reasoning）标注，适合训练具有可解释性的心理咨询模型和思维链能力。多任务标签支持情绪识别和策略分类。中文部分规模较小（431会话），作为微调主数据偏小，适合作为高质量补充或推理能力训练数据。中英对照可用于翻译增强。
11. MDD-5k
中文 免费 已查证
来源：GitHub / AAAI 2025
规模：4,630-5,000条诊断对话（基于926-1000份真实匿名病历）
许可：未明确声明（GitHub公开）
格式：医生-患者多轮对话 + 诊断结果 + 治疗建议标签
与上海市精神卫生中心合作，基于真实匿名病历通过神经符号多智能体合成。含诊断标签和治疗建议，适合训练具有诊断推理能力的心理大模型。临床真实性高于纯生成数据。但为精神科临床诊断场景（非一般心理咨询），约90%患者年龄20-40岁，与校园场景有差异。
12. C-IMHI (MentalGLM)
中文 免费 已查证
来源：GitHub / EMNLP 2025 Main
规模：约9,000条指令样本（含质量控制和人工验证）
许可：未明确声明（GitHub公开）
格式：多任务指令（自杀风险检测/认知扭曲检测/认知路径提取）+ 可解释决策说明
指令格式直接适配大模型微调，含可解释性标注（决策理由），适合训练能给出分析依据的心理健康分析模型。基于 SOS-HL-1K、SocialCD-3K 等数据构建。覆盖社交媒体文本而非咨询对话，主要用于分析/检测而非生成回复，9K规模中等。可作为校园心理模型的危机检测辅助能力训练数据。

五、第二梯队：需申请/付费/许可受限的中文数据

这些数据集质量较高但获取有门槛，建议在第一梯队数据不足或需要特定方向补充时考虑。

1. efaqa-corpus-raw — 迄今公开最大的中文心理咨询原始语料
中文 需付费 已查证
来源：GitHub
规模：172,316话题 / 2,381,273消息 / 4451万字
许可：春松许可证v1.0，仅限研究用途，需购买证书
格式：未标注原始多轮对话（爬取自壹心理、简心理、豆瓣等）
规模极大，非常适合无监督预训练或继续预训练。包含真实用户倾诉与网友回复，话题覆盖学业、情感、家庭、职场、抑郁焦虑等。需付费购买证书，非免费；未标注，需自行清洗和构造 instruction 格式；数据来自网络爬取，质量参差不齐；许可禁止商用和二次分发；部分来源网站已关闭，有合规风险。

中文 需申请 已查证

九、微调选型建议

基于你"微调本地小模型 + 对当前数据集质量有疑问 + 寻找替代/补充/评估数据"的场景，给出以下分层建议。

🥇 首选组合（直接可用，中文，免费）

  1. 主力训练集：SoulChatCorpus（258K对话/151万轮，已格式化，学生场景覆盖好）+ CPCD（9万对话，唯一校园专属，补充校园场景特异性）。两者混合可兼顾规模和校园相关性。
  2. 高质量补充：CPsyCounD（3.1K真实报告重构，作为高质量种子数据提升回复专业度）+ SMILECHAT（55K对话，基于真实QA扩展，含真实测试集可做评估）。
  3. 如需要可商用：EmoLLM 数据集集合（MIT许可，16个子集，已整合上述多个数据集，配套微调配置）。这是唯一明确可商用的选项。

🥈 定向增强（根据模型能力短板选择）

  1. 需要长程对话能力：加入 PsyDial（平均37.8轮，隐私保护重构）或 PsyDTCorpus（平均18轮，咨询师流派风格）。
  2. 需要推理/可解释能力：加入 SoulChat-R1（显式CoT）+ Psy-Insight（逐步推理标注）+ EmoLLM中的psychology-10k-Deepseek-R1-zh（R1蒸馏数据）。
  3. 需要CBT取向/抑郁方向：加入 cPsychQASet（89K CBT问答三元组，真实论坛数据）。
  4. 需要危机检测能力：加入 C-IMHI/SOS-HL-1K/SocialCD-3K（MentalGLM项目，免费，指令格式）。
  5. 需要临床诊断能力：加入 MDD-5k（基于真实病历，免费）或申请 D4（抑郁问诊，EMNLP 2022）。

🥉 有门槛但值得关注（需申请/付费）

  1. 预训练语料：efaqa-corpus-raw（4451万字，迄今最大中文心理咨询原始语料）— 如有预算，适合做继续预训练，显著提升模型在心理领域的语言基础。
  2. 学术基准：PsyQA（22K/56K，奠基性数据集）— 申请获取后可作为评估基准，与 SMILECHAT 的 PsyTest 配合使用。
  3. 青少年场景：DeepWell-Adol（1,795条，13.5岁）— 如模型面向中学生，关注论文发布后的数据开放。
  4. 大规模补充：CPsDD（68K对话）和 AuraDial（30万+单轮）— 联系作者确认下载方式。

✅ 数据质量评估建议（针对你对当前数据集质量的疑问）

  1. 用高质量数据集做评估基准：将 CPsyCounE（500条评估对话）、PsyTest（SMILECHAT真实测试集）、CPCD-Bench 作为标准评估集，对比你当前模型和用新数据微调后的模型表现。
  2. 合成数据 vs 真实数据比例：当前主流数据集多为 LLM 合成，建议确保训练集中有一定比例的真实/半真实数据（CPsyCounD 基于真实报告、cPsychQASet 来自真实论坛、MDD-5k 基于真实病历），避免模型学到合成数据的模式化表达。
  3. 校园场景筛选：从通用数据集中按关键词（学业、考试、宿舍、考研、就业、导师、同学关系、失恋、焦虑等）筛选校园相关子集，统计占比，评估当前数据的校园场景覆盖度。
  4. 多维度质量检查：检查数据中的回复长度分布、共情表达多样性、咨询策略覆盖度、危机干预正确性（是否有鼓励自残等危险回复）、文化适配性（是否有不符合中国校园文化的建议）。
  5. 去重和清洗：EmoLLM 已用 Simhash 去重，其他数据集可能存在重复样本，混合使用前建议统一去重。同时过滤掉低质量、过短、无关或有安全风险的样本。

十、注意事项与伦理提醒

⚠️ 许可与合规

  • 仅 EmoLLM 数据集集合明确采用 MIT 许可可商用。多数数据集未声明许可或仅限研究用途，商用前务必逐一核实许可条款。
  • EFAQA 系列（春松许可证）需购买证书且禁止商用和二次分发；PsyQA/STAMPsy/D4 需签署协议申请；AuraDial 需非商业协议。
  • efaqa-corpus-raw 数据来自网络爬取，虽经脱敏但仍有隐私合规风险，部分来源网站已关闭。

🔬 数据真实性

  • 多数多轮对话由 LLM 合成（SoulChat、SMILECHAT、CPCD、PsyDTCorpus 等），可能存在模式单一、缺乏真实咨询深度、回复风格趋同等问题。
  • 相对真实的数据包括：CPsyCounD（真实报告重构）、cPsychQASet（真实论坛）、MDD-5k（真实病历合成）、efaqa-corpus-raw（网络爬取真实用户倾诉）。
  • 建议训练集中保留一定比例真实/半真实数据，避免模型完全学到合成数据的表达模式。

🛡️ 安全与伦理

  • 心理咨询数据用于模型微调时，应在模型端做好安全对齐：自杀/自残干预、危机识别、转介专业帮助等，AI 不可替代真实心理咨询。
  • 危机文本数据（SOS-HL-1K等）涉及自杀等高敏感内容，使用需伦理审查，训练时需确保模型不会学到危险行为。
  • PsyDial 采用 RMRR 方法专门做了隐私保护重构，是伦理上最稳妥的长程对话选择。
  • 面向未成年人（DeepWell-Adol，13.5岁）的数据使用需额外注意未成年人保护相关法规。

📝 查证说明

  • 标注"已查证"的数据集：其来源链接、核心字段（规模/类型/许可）经多源交叉验证或直接读取官方 README/论文确认。
  • 标注"一方称"的数据集（CPsDD、AuraDial、灵溪语音问诊等）：仅从单一来源获取信息，未交叉验证到独立可访问的下载地址，建议使用前直接联系作者确认。
  • 部分数据集的 HuggingFace 页面在调研环境中无法直接访问，其 URL 从 GitHub README 中核实列出，可在正常网络环境下访问。
  • 调研时间为 2026-08-31，数据集可能持续更新，建议使用前再次确认最新状态。
